## Résumé
Un CV interrogeable : une base de connaissances publique sur Alexandre, servie via un chat web et un serveur MCP pour que les recruteurs et les agents IA puissent poser des questions et obtenir des réponses sourcées et citées. Conçu pour être radicalement transparent — la base, le prompt système et le code sont tous open-source.

## Pourquoi
Deux raisons. D'abord, les workflows de recrutement passent de plus en plus par des agents IA ; un CV statique se prête mal à cette interface. Ensuite, la transparence sur ce qu'un agent « sait » de vous est un problème de confiance qui mérite d'être traité dès le départ.
